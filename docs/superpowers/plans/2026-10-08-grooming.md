> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Read `CLAUDE.md` at the repo root first; it holds the build commands and the invariants every review enforces.

**Goal:** Turn the Platform grooming runbook into the Grooming screen: a pre-check mode that triages `New` tickets and promotes them to `Planning`, a report writer and parser compatible with the Claude-driven pre-check reports, and an epic-by-epic session mode that accepts, bounces, or parks `Planning` tickets.

**Architecture:** The existing `Store` already holds every open team ticket with status and parent, so grooming is a set of pure projections (`grooming.rs`) plus a view (`views/grooming.rs`) that pushes `Action`s. Writes go through the ordered write worker as today. Task 1 first splits the 1300-line `app.rs` into submodules and adds a windowless `App` constructor so the grooming state machine can be unit-tested without a window.

**Tech Stack:** Rust 2024, eframe/egui 0.36.2, existing crate modules (`jira`, `store`, `adf`, `keys`, `theme`, `views`). Toolchain via `nix develop` only.

**Spec:** `docs/superpowers/specs/2026-10-07-jira-tickets-design.md`, section 7 (Grooming view) and the runbook it cites: `the team's grooming runbook` in the team's monorepo.

The `New → Planning` transition id is `cfg.grooming.planning_transition_id` (`"11"`); other transitions are looked up per issue by target status name via `Client::transitions`.

- Pre-check promotion performs only `New → Planning` transitions: no comment, no fields, no resolution, nothing else. Bounce (`Planning → New`) requires a non-empty comment and posts it before the transition. Park is `Planning → Backlog`. Accept is `Planning → Ready for Work` plus one rank call.

- All writes via `App::spawn_write` after `jira::check_writable`; all reads via `App::spawn`; loading flags only after `should_load`. New keys go into `keys::BINDINGS` first (README table test).
- Status colour for `Work in Progress` must map to the in-progress hue (add it to the name map in `theme::status_tint`); the live team uses that name, not `In Progress`.

Parsing rules: sections start at `## ` headings; only "Planning — by epic" and "Needs detail" are consumed (anything else is ignored). Within a section, `### [KEY Summary](url)` sets the current epic (key = first token, summary = rest, numeric id from `issueParent=`); an older plain `### Epic [KEY](url) · Summary · Status` form must also parse. Rows start with `- [KEY](url) — summary` followed by ` · ` separated annotations; `rank N`, `created YYYY-MM-DD`, `new (Nd)` / `older`, and `missing: a, b` are extracted by prefix; other annotations are ignored. Lines under "Existing Ready for Work in this epic" are skipped (they are not promoted candidates). `~~KEY~~` anywhere in the two consumed sections records a struck key. The date comes from the `# ... — YYYY-MM-DD` title.

```rust
//! Pre-check reports: parse the files the Claude-driven `team-pre-check` writes
//! (and this app's own), and write this app's reports in the plugin template.

use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, PartialEq, Default)]
pub struct EpicRef { pub key: String, pub summary: String, pub numeric_id: Option<String> }

#[derive(Debug, Clone, PartialEq, Default)]
pub struct PlanningRow { pub key: String, pub summary: String, pub rank: Option<u32>, pub age: Option<String>, pub epic: Option<String> }

#[derive(Debug, Clone, PartialEq, Default)]
pub struct NeedsDetailRow { pub key: String, pub summary: String, pub rank: Option<u32>, pub created: Option<String>, pub codes: Vec<String>, pub epic: Option<String> }

#[derive(Debug, Clone, PartialEq, Default)]
pub struct Report {
    pub date: String,
    pub promoted: Vec<PlanningRow>,
    pub needs_detail: Vec<NeedsDetailRow>,
    pub epics: BTreeMap<String, EpicRef>,
    pub struck: Vec<String>,
}

#[derive(Debug, Clone, PartialEq)]
pub enum Badge { Promoted, NeedsDetail(Vec<String>), Struck }

#[derive(PartialEq)]
enum Section { Other, Planning, NeedsDetail }

pub fn parse(text: &str) -> Report {
    let mut r = Report::default();
    let mut section = Section::Other;
    let mut epic: Option<String> = None;
    let mut in_existing = false;
    for line in text.lines() {
        let t = line.trim_end();
        if let Some(title) = t.strip_prefix("# ") {
            if let Some((_, d)) = title.rsplit_once("— ") {
                r.date = d.trim().to_string();
            }
            continue;
        }
        if let Some(h) = t.strip_prefix("## ") {
            section = if h.starts_with("Planning") { Section::Planning } else if h.starts_with("Needs detail") { Section::NeedsDetail } else { Section::Other };
            epic = None;
            in_existing = false;
            continue;
        }
        if section == Section::Other { continue; }
        if let Some(h) = t.strip_prefix("### ") {
            in_existing = false;
            epic = parse_epic_heading(h).map(|e| { let k = e.key.clone(); r.epics.insert(k.clone(), e); k });
            continue;
        }
        if t.starts_with("Existing Ready for Work") { in_existing = true; continue; }
        if t.is_empty() { continue; }
        if !t.starts_with("- ") { continue; }
        for s in struck_keys(t) { if !r.struck.contains(&s) { r.struck.push(s); } }
        if in_existing { continue; }
        let Some((key, summary, notes)) = parse_row(t) else { continue };
        match section {
            Section::Planning => r.promoted.push(PlanningRow {
                key, summary, rank: note_u32(&notes, "rank "), age: notes.iter().find(|n| *n == "older" || n.starts_with("new (")).cloned(), epic: epic.clone(),
            }),
            Section::NeedsDetail => r.needs_detail.push(NeedsDetailRow {
                key, summary, rank: note_u32(&notes, "rank "), created: note_str(&notes, "created "),
                codes: note_str(&notes, "missing: ").map(|c| c.split(',').map(|x| x.trim().to_string()).filter(|x| !x.is_empty()).collect()).unwrap_or_default(),
                epic: epic.clone(),
            }),
            Section::Other => {}
        }
    }
    r
}

/// `[CI-1860 Progressive Delivery](url?issueParent=10001)` or `Epic [CI-79](url) · Cluster Operations (ongoing) · In Progress` or `(no epic)`.
fn parse_epic_heading(h: &str) -> Option<EpicRef> {
    let h = h.trim();
    if h.starts_with("(no epic)") { return None; }
    let h = h.strip_prefix("Epic ").unwrap_or(h);
    let open = h.find('[')?;
    let close = h[open..].find("](")? + open;
    let inner = &h[open + 1..close];
    let rest = &h[close + 2..];
    let url_end = rest.find(')').unwrap_or(rest.len());
    let url = &rest[..url_end];
    let after = rest.get(url_end + 1..).unwrap_or("");
    let numeric_id = url.split("issueParent=").nth(1).map(|s| s.chars().take_while(|c| c.is_ascii_digit()).collect::<String>()).filter(|s| !s.is_empty());
    let (key, summary) = match inner.split_once(' ') {
        Some((k, s)) => (k.to_string(), s.trim().to_string()),
        None => (inner.to_string(), after.split('·').nth(1).map(|s| s.trim().to_string()).unwrap_or_default()),
    };
    Some(EpicRef { key, summary, numeric_id })
}

/// `- [CI-1](url) — summary · note · note` → (key, summary, notes). Struck rows (`- ~~CI-1~~ — …`) return None.
fn parse_row(t: &str) -> Option<(String, String, Vec<String>)> {
    let body = t.strip_prefix("- ")?;
    let body = body.strip_prefix(|c: char| c.is_ascii_digit()).unwrap_or(body);
    let open = body.find('[')?;
    if body[..open].contains("~~") { return None; }
    let close = body[open..].find("](")? + open;
    let key = body[open + 1..close].to_string();
    let after = &body[close + 2..];
    let paren = after.find(')')?;
    let rest = after[paren + 1..].trim_start();
    let rest = rest.strip_prefix("— ").or_else(|| rest.strip_prefix("- ")).unwrap_or(rest);
    let mut parts = rest.split(" · ").map(|s| s.trim().to_string());
    let summary = parts.next().unwrap_or_default();
    Some((key, summary, parts.collect()))
}

fn struck_keys(t: &str) -> Vec<String> {
    let mut out = Vec::new();
    let mut rest = t;
    while let Some(i) = rest.find("~~") {
        let after = &rest[i + 2..];
        let Some(j) = after.find("~~") else { break };
        let k = after[..j].trim();
        if k.contains('-') && k.chars().all(|c| c.is_ascii_alphanumeric() || c == '-') { out.push(k.to_string()); }
        rest = &after[j + 2..];
    }
    out
}

fn note_str(notes: &[String], prefix: &str) -> Option<String> {
    notes.iter().find_map(|n| n.strip_prefix(prefix).map(|s| s.trim().to_string()))
}
fn note_u32(notes: &[String], prefix: &str) -> Option<u32> {
    note_str(notes, prefix).and_then(|s| s.split_whitespace().next().and_then(|n| n.parse().ok()))
}

impl Report {
    pub fn badge_for(&self, key: &str) -> Option<Badge> {
        if self.struck.iter().any(|k| k == key) { return Some(Badge::Struck); }
        if self.promoted.iter().any(|p| p.key == key) { return Some(Badge::Promoted); }
        self.needs_detail.iter().find(|n| n.key == key).map(|n| Badge::NeedsDetail(n.codes.clone()))
    }
}

/// Newest `YYYY-MM-DD.md` in `dir`; other names only when no plain-dated file exists.
pub fn latest(dir: &Path) -> Option<(PathBuf, Report)> {
    let mut plain: Vec<PathBuf> = Vec::new();
    let mut other: Vec<PathBuf> = Vec::new();
    for e in std::fs::read_dir(dir).ok()?.flatten() {
        let p = e.path();
        let Some(name) = p.file_name().and_then(|n| n.to_str()) else { continue };
        if !name.ends_with(".md") { continue; }
        let stem = &name[..name.len() - 3];
        let dated = stem.len() == 10 && stem.chars().enumerate().all(|(i, c)| if i == 4 || i == 7 { c == '-' } else { c.is_ascii_digit() });
        if dated { plain.push(p) } else { other.push(p) }
    }
    let pick = if plain.is_empty() { other } else { plain };
    let p = pick.into_iter().max()?;
    let text = std::fs::read_to_string(&p).ok()?;
    Some((p, parse(&text)))
}
```
